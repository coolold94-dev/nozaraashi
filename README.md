# نوزراشى

نظام إدارة **سوبر ماركت جملة مصري** يعمل **أوفلاين** بالكامل.

## التشغيل

```bash
npm install
npm run dev
```

افتح المتصفح على العنوان اللي يظهر (غالباً `http://localhost:5173`).

## تسجيل الدخول التجريبي

| المستخدم | كلمة المرور | الدور |
|----------|-------------|-------|
| admin | 1234 | مدير |
| cashier | 1234 | كاشير |

## المميزات (المرحلة 1)

- واجهة عربية RTL
- تخزين محلي IndexedDB (Dexie)
- تسجيل دخول وصلاحيات
- إعدادات المحل
- لوحة تحكم
- نسخ احتياطي / استرجاع JSON
- PWA — يشتغل أوفلاين من المتصفح

## المرحلة 2 (قادمة)

- نقطة بيع جملة (كرتونة / باكت / قطعة)
- حسابات آجل وتحصيل
- مشتريات وموردين
- تقارير
- تطبيق ديسكتوب (Tauri)

## البناء للإنتاج

```bash
npm run build
npm run preview
```
